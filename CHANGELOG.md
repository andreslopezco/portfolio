# Changelog

## [2.0.2] - 2025-10-04

### Refactoring

- Se realizó un refactoring del código que incluye:
  - Reorganización de directorios y archivos.
  - Actualización de importaciones para reflejar la nueva estructura.
  - Separación de componentes en archivos individuales para mejorar la modularidad.
  - Implementación de componentes en archivos Astro.

### Cambios en dependencias

- **Actualización de dependencias**:
  - Actualizada `@radix-ui/react-dialog` de `^1.1.6` a `^1.1.7`.
  - Agregada `shadcn-ui` como nueva dependencia (`^0.9.5`).

### Cambios en archivos de configuración

- Cambiado el nombre del proyecto de `portfolio-astro` a `portfolio`.
- Actualizada la versión a `2.0.2` en `package.json` y `package-lock.json`.

### Eliminación de archivos

- Eliminados archivos de imagen correspondientes a la versión v1.0.0: `favicon.svg`, `logo.png`, y otros relacionados con proyectos.
